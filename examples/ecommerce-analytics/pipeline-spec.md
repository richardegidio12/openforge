## Epic 1 — Ingestion (Bronze)

### HIST-004: Incremental ingestion — `orders` table from ERP
**Context:** Dagster connector that reads new/updated orders from the ERP PostgreSQL (Tiny) since the last watermark and saves them to GCS Bronze as Parquet, partitioned by ingestion date.

**Acceptance criteria:**
- [ ] Incremental ingestion by `updated_at` (watermark persisted in BigQuery)
- [ ] Raw data preserved — no transformation, original ERP schema maintained
- [ ] Metadata added: `_ingested_at`, `_source = 'erp_tiny'`, `_batch_id`
- [ ] Retry with backoff: 3 attempts, delays of 2min/5min/10min
- [ ] Failure does not corrupt previous data (atomic write)
- [ ] Job scheduled: 01:30 BRT daily
- [ ] Alert triggered if job fails → #data-platform
- [ ] Backfill executed: 01/01/2023 to D-1 — validated with IT (~850k records)
- [ ] Dedup of `order_id` applied (workaround for ERP bug), with log of discarded records

**Estimated effort:** 3 days
**Dependencies:** HIST-001, HIST-002
**Responsible:** Rafael Torres
**Risk:** ERP duplicate bug — implement dedup with auditable log

## Epic 2 — Transformation and Cleaning (Silver)

### HIST-007: Silver — orders
**Context:** Transform raw order data: type, deduplicate, calculate net_revenue, remove PII, implement data contract tests.

**Acceptance criteria:**
- [ ] Deduplication by `order_id` (keep most recent by `_ingested_at`)
- [ ] Correct typing: dates as DATE/TIMESTAMP, amounts as DECIMAL(10,2)
- [ ] PII removed: `customer_email` hashed (SHA-256), `customer_cpf` and `customer_phone` removed
- [ ] `net_revenue_brl` calculated: `order_amount_brl - COALESCE(discount_amount_brl, 0)`
- [ ] dbt tests implemented and passing:
  - `order_id`: not_null, unique
  - `order_status`: accepted_values
  - `order_amount_brl`: not_null, expression `>= 0`
  - `net_revenue_brl <= order_amount_brl`
- [ ] Schema documented in `schema.yml`
- [ ] Bronze → Silver lineage traceable in Dagster

**Estimated effort:** 2.5 days
**Dependencies:** HIST-004
**Responsible:** Rafael Torres
