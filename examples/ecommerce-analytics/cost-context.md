## Cost Guardrails

These rules must be respected throughout the build and in production:

1. **BigQuery queries must use partitioning** — all Silver and Gold tables partitioned by date. Full table scans are prohibited in production queries.
2. **Dagster job parallelism capped at 3 concurrent runs** — prevent unexpected compute spikes.
3. **GCS lifecycle policy** — Bronze data older than 1 year moved to Nearline storage (cost ~40% lower). Bronze data older than 3 years moved to Coldline.
4. **No BigQuery reserved slots** — on-demand pricing is sufficient at current volume (~2k orders/day). Re-evaluate if monthly processed bytes exceed 5TB.
5. **Alert threshold** — GCP billing alert configured at $200/month. Notify Bruno Costa if triggered.
6. **PagSeguro API (phase 2)** — additional API calls will increase BigQuery query volume. Re-evaluate cost before Phase 2 implementation.
