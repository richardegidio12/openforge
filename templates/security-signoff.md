## Detailed checklist

### IAM & Least Privilege
- [ ] All service accounts follow least-privilege principle (no owner/editor roles)
- [ ] Bronze layer accessible only to ingestion-sa and transformation-sa
- [ ] Gold layer: BI SA and analysts have read-only access
- [ ] Human access to production data goes through audited accounts
- [ ] Offboarding process documented

### Secrets & Credentials
- [ ] No credentials in code or repository (confirmed via git grep)
- [ ] All secrets in managed secret store
- [ ] dbt `profiles.yml` not committed (confirmed in .gitignore)
- [ ] SA key rotation policy defined (or Workload Identity used)
- [ ] External API keys documented and rotation policy exists

### Encryption
- [ ] Encryption at rest confirmed for all storage layers
- [ ] All connections use TLS
- [ ] Column-level encryption applied where required by data contract

### Network Isolation
- [ ] No data service with unnecessary public IP
- [ ] BI tool connects via private or controlled endpoint
- [ ] Firewall / VPC rules reviewed
- [ ] Outbound connections to external APIs are intentional and documented

### Audit Logging
- [ ] Dataset-level audit logging enabled in production
- [ ] Pipeline logs do not contain raw PII
- [ ] Log retention policy defined
- [ ] Access anomaly alerting configured (or explicitly deferred with justification)

### Compliance (complete only if applicable)
- [ ] Data residency confirmed (region matches legal requirement)
- [ ] Breach notification process documented
- [ ] IaC changes tracked in version control
